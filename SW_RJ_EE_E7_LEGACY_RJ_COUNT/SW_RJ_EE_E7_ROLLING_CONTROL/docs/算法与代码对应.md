# 算法、接口与修改范围

## 目标分布

状态 m 是浮动核数 npt、全部有效核深度/速度及由此确定的分层模型。能量为固定误差高斯似然的失配项：

E(m) = 0.5 * sum_j ((d_j - g_j(m))/sigma_j)^2。

第 i 链目标为 p(m) exp[-beta_i E(m)]，beta=1/T。p(m) 在各温度链间相同且不回火。省略的是与模型无关的似然归一化常数，未删掉 RJ 的先验或提议密度项。

若开启已有截断分支，定义 h_i(m)=beta_i max(E(m),H_i)，冷链 H_1=-Inf。局部接受率中的似然差变成 h_i(x)-h_i(y)，再加原先验比、正反提议比和原 Jacobian 项。默认全部 H=-Inf。

## EE 接受率

对固定链对分区 D_{i,b}，理想供体建议为：

q_i(y|x) = pi_{i+1}(y) 1[y in D_{i,b(x)}] / pi_{i+1}(D_{i,b(x)})。

x、y 在同一个环，正反归一化分母相同。两条链共用 p(m)，从而理想 MH 对数比为：

log alpha = min(0, h_i(x)-h_i(y)+h_{i+1}(y)-h_{i+1}(x))。

未截断时就是 min(0,(beta_i-beta_{i+1})*(E_x-E_y))。

因此，不同链对可以使用不同固定分区，但每对链的正反候选必须用同一分区。若额外按 npt 重新赋权、偏爱大结构差异或删去重复历史，就改变了建议分布，不能继续直接照搬这个简式。

实际程序用有限历史经验分布代替理想供体。上述推导解释简式的来源，不构成有限历史算法每一轮精确不变性的证明。固定边界后档案继续增长，算法仍依赖历史。

## RJ 改了什么

相对 `SW_RJ_EE_TUNING`，`RJ_C_mian.m`、`Move.m`、`Change.m`、两个先验密度函数、层模型转换、正演函数、原后验收集及原三张绘图函数保持原文件内容。清单见 `BASELINE_MANIFEST.json`。

`Birth.m`、`Death.m` 接入之前 A 版的可关闭深度提议。默认 `enable_a=false`，Birth 仍在整个深度区间均匀取一个位置；Death 仍均匀删一个浮动核，原比率分支不变。自检会与保留的 TUNING 参考函数逐轮比较状态和随机数流。

A 开启时，以权重 w 从已有 K 个有效核附近的裁剪窗口均匀选位置，以 1-w 从全区间均匀选位置；重叠窗口密度要相加：

q_z(z|m) = (1-w)/D + w/K * sum_j 1[z in W_j]/length(W_j)。

Birth 在原接受率里将 1/D 替换为此 q_z；Death 反向项必须在删除后的模型上重新计算。全局分支权重始终大于0，避免仅靠局部窗口限制可达位置。先验和删核方式不因 A 改变。

速度混合提议 q_v 是两条正规化高斯密度的加权和，正反比率使用同一边际混合密度，不只使用抽中的那条高斯密度。沿用已测试的 TUNING 实现。

## E5顺序组合核

E4以前每轮在局部RJ与EE之间二选一。E5将更新核改为：

1. 所有温度链各执行一次原有 `RJ_C_mian`；
2. 对有更高温供体的链，以 `ee_probability` 决定是否追加一次EE；
3. 可选PT交换；
4. 每条链的最终状态只写入历史一次。

因此EE未选中、供体不足或被拒绝，都不会抹掉本轮已经完成的局部RJ结果。
EE候选仍只来自以前轮次的FIFO档案。两个核各自保持相应目标时，顺序组合也保持
该目标；有限自适应历史的实际收敛仍须在最终冻结后通过多种子诊断验证。

## 参数时间线

当前默认40000轮：1001:3000首次校准，3001:4000填充历史，
4001轮起追加EE；预热期每2000轮用最近4000轮重算成对边界，
18000轮最终冻结并清空过渡档案，18001:20000重新填充，20001:40000
收集后验。FIFO每链保留最近4000个完整状态。后验薄化不影响EE历史。

如果要把校准移到10001:15000，必须相应增加总预算、填充期和burn-in，例如：

```matlab
cfg.nsample = 30000;
cfg.burn_in = 20000;
cfg.ee_calibration_start = 10001;
cfg.ee_calibration_end = 15000;
cfg.ee_jump_start = 17001;
```

这只是可运行时间安排，不保证更好。不能保留20000总轮次却把绝大部分用于预热，再与保留10000轮的旧实验直接比较准确性。

## 来源定位

底层是用户 TUNING 的 Voronoi RJ 跨维面波反演。EE 保留 DIM_MATLAB_Core 所启发的固定环、按历史时间条目均匀回放、相邻温度提供候选的组织；可选截断沿用既有分支。新增链对校准与稀疏合并是本项目工程方案。没有完整移植 DIM 的 BSP 或跨维独立建议模块，没有实现 Schreck 的持续分位数 AEE。
